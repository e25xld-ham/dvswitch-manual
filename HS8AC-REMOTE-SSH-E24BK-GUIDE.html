Quick Start

  1. ตรวจว่ามี OpenSSH ด้วย ssh.exe -V
  2. ติดตั้ง cloudflared รุ่น Windows 64-bit
  3. รันคำสั่งเชื่อมต่อด้านล่าง
  4. กรอกอีเมลที่ได้รับอนุญาตและ OTP
  5. ตรวจ Host Key ก่อนพิมพ์ yes
  6. ใส่รหัสผ่านของ user admin
ssh.exe -o "ProxyCommand=cloudflared.exe access ssh --hostname %h" admin@ssh-bk.hs8ac.com

1. เตรียมคอม Windows เครื่องใหม่

1

ตรวจ OpenSSH Client

ssh.exe -V

ถ้าแสดงรุ่น OpenSSH แปลว่าพร้อมใช้งาน

2

ถ้าไม่มี OpenSSH

เปิด PowerShell แบบ Run as Administrator แล้วตรวจ:

Get-WindowsCapability -Online | Where-Object Name -like 'OpenSSH.Client*'

ติดตั้งด้วย:

Add-WindowsCapability -Online -Name OpenSSH.Client~~~~0.0.1.0
3

ดาวน์โหลด cloudflared MSI

เปิด PowerShell ปกติ แล้วรันทีละบรรทัด:

$msi = Join-Path $env:TEMP 'cloudflared-windows-amd64.msi' Invoke-WebRequest -UseBasicParsing -Uri 'https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.msi' -OutFile $msi Get-Item $msi | Select-Object FullName,Length,LastWriteTime
4

ตรวจลายเซ็นก่อนติดตั้ง

Get-AuthenticodeSignature $msi | Select-Object Status,StatusMessage,@{Name='Signer';Expression={$_.SignerCertificate.Subject}}

ผลที่ยอมรับได้ต้องเป็น Status: Valid และ Signer เป็น Cloudflare, Inc.

ถ้า Status ไม่ใช่ Valid ห้ามติดตั้ง อย่ากดข้ามคำเตือน
5

ติดตั้ง cloudflared

$arguments = "/i `"$msi`" /passive /norestart" $p = Start-Process -FilePath "msiexec.exe" -ArgumentList $arguments -Verb RunAs -Wait -PassThru Write-Host "MSI_EXIT_CODE=$($p.ExitCode)"

กด Yes เมื่อ Windows แสดง UAC ผลสำเร็จปกติคือ MSI_EXIT_CODE=0

6

Refresh PATH และตรวจรุ่น

$env:Path = [Environment]::GetEnvironmentVariable("Path","Machine") + ";" + [Environment]::GetEnvironmentVariable("Path","User") cloudflared.exe --version

ถ้ายังไม่พบ ให้ปิดแล้วเปิด PowerShell ใหม่ หรือตรวจตรง:

& "C:\Program Files (x86)\cloudflared\cloudflared.exe" --version
7

ตรวจ DNS

Resolve-DnsName ssh-bk.hs8ac.com

IP ที่แสดงอาจเป็น Cloudflare edge address ไม่ใช่ Public IP ของ Pi ถือว่าปกติ

2. เชื่อมต่อ SSH

ssh.exe -o "ProxyCommand=cloudflared.exe access ssh --hostname %h" admin@ssh-bk.hs8ac.com

ลำดับการทำงาน

  1. เบราว์เซอร์จะเปิดหน้า Cloudflare Access
  2. กรอกอีเมลผู้ดูแลที่ได้รับอนุญาต
  3. กด Send login code
  4. เปิดอีเมล แล้วกรอก OTP
  5. กลับมาที่ PowerShell เดิม
  6. ครั้งแรก OpenSSH จะถาม Host Key
  7. ตรวจ fingerprint ให้ตรงก่อนพิมพ์ yes
  8. ใส่รหัสผ่าน user admin — ตัวอักษรจะไม่แสดง

เมื่อสำเร็จจะเห็น:

admin@HS8AC-E24BK:~ $

ตรวจว่าเข้าเครื่องถูกตัว

hostname whoami uname -m

ผลที่คาดหวัง:

HS8AC-E24BK admin aarch64

ตรวจบริการแบบ Read-only

systemctl is-active ssh.service systemctl is-active cloudflared.service systemctl is-active asterisk.service
ข้อห้าม: ห้ามใช้ rpt restart ห้าม Restart Asterisk ห้ามเชื่อม/ตัด Node และห้ามส่ง RF โดยไม่มีการอนุมัติ

ออกจาก SSH:

exit

3. ตรวจ SSH Host Key อย่างปลอดภัย

ก่อนเดินทาง ให้เปิด Cockpit Terminal หรือ session ที่เชื่อถือได้บน Pi แล้วรัน:

sudo ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub

เก็บ fingerprint ไว้ใน password manager หรือบันทึกส่วนตัว

ถ้าขึ้น WARNING: REMOTE HOST IDENTIFICATION HAS CHANGED ห้ามลบ known_hosts ทิ้งทันที และห้ามใช้ StrictHostKeyChecking=no ให้หยุดแล้วตรวจ fingerprint ใหม่ก่อน

4. ตั้งคำสั่งสั้นแบบถาวร (ทางเลือก)

สร้างโฟลเดอร์และเปิดไฟล์ config:

New-Item -ItemType Directory -Path "$env:USERPROFILE\.ssh" -Force notepad "$env:USERPROFILE\.ssh\config"

ใส่เนื้อหานี้:

Host hs8ac-e24bk HostName ssh-bk.hs8ac.com User admin ProxyCommand cloudflared.exe access ssh --hostname %h

จากนั้นใช้คำสั่งสั้น:

ssh hs8ac-e24bk

ตรวจ config โดยยังไม่เชื่อม:

ssh.exe -G hs8ac-e24bk | Select-String 'hostname|user|proxycommand'

5. แก้ปัญหาเบื้องต้น

อาการสาเหตุ/วิธีแก้
cloudflared.exe is not recognizedเปิด PowerShell ใหม่ หรือใช้ path C:\Program Files (x86)\cloudflared\cloudflared.exe
Browser ไม่เปิดCopy URL ที่ cloudflared แสดงใน PowerShell ไปเปิดเอง ห้ามแชร์ URL นี้
OTP ไม่มาตรวจ Spam/Junk และต้องใช้อีเมลเดียวกับที่ได้รับอนุญาตใน Access Policy
Access denied ก่อนถามรหัสผ่าน SSHอีเมลไม่ตรง Policy หรือ OTP/Access session ไม่ผ่าน
Permission deniedรหัสผ่าน user admin ไม่ถูกต้อง
Connection timed out / closedตรวจอินเทอร์เน็ต ตรวจ Tunnel ใน Cloudflare และตรวจ cloudflared.service บน Pi ผ่านช่องทางที่เชื่อถือได้
Host key changedหยุดทันที แล้วตรวจ fingerprint จาก Pi อย่าลบ known_hosts แบบสุ่ม
ssh admin@ssh-bk.hs8ac.com เข้าไม่ได้เป็นเรื่องปกติ เพราะต้องใช้ ProxyCommand ผ่าน cloudflared

6. สิ่งที่ห้ามเก็บหรือส่งต่อ

  • Tunnel token ที่ขึ้นต้นประมาณ eyJ...
  • คำสั่ง cloudflared service install ที่มี token
  • รหัสผ่าน user admin
  • OTP
  • Private SSH key เช่นไฟล์ id_ed25519
  • Access login URL ที่มี query string/token
  • Screenshot ที่มองเห็นข้อมูลลับ

เครื่อง Client ต้องมีเพียง OpenSSH, cloudflared, สิทธิ์เข้าถึงอีเมลผู้ดูแล และรหัสผ่าน admin ในสถานะปัจจุบัน

7. Termius / มือถือ

การตั้ง Termius แค่:

Host: ssh-bk.hs8ac.com Port: 22 User: admin

ยังไม่เพียงพอ เพราะวิธีปัจจุบันต้องมี cloudflared access ssh เป็น client-side ProxyCommand

คู่มือนี้รองรับ Windows OpenSSH เท่านั้น การใช้ Termius Mobile ต้องทำ Cloudflare One/WARP private route และ policy แยกใน Phase อื่น

หมายเหตุการ Hardening ในอนาคต

ขณะนี้ user admin ยังใช้รหัสผ่าน SSH ได้ และยังไม่มี public key ใน /home/admin/.ssh/authorized_keys

ขั้นต่อไปที่ควรทำคือเพิ่ม SSH public key ทดสอบให้สำเร็จ แล้วค่อยพิจารณาปิด PasswordAuthentication ภายหลัง ห้ามปิดก่อนทดสอบ key จริง
